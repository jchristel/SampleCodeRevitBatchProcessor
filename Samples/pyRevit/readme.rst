This is an extension which showcases how to use the pyRevit API together wih duHast.

This extension covers the following topics:

- Families
  - Catalogue files
  - Batch import and export
  - Batch reload families
  - Batch rename / copy families
  - Report family properties
  - Swap family types
- Levels and Grids
    - Conversion to 2D
    - Toggle head visibility
    - Apply grids visibility and extend to many views
- Purge unused element
   - Shared parameters
   - Views and legends
   - fill patterns
   - Line patternss and styles
- View templates
- Warnings
