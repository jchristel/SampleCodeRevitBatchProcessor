## Deployment Locations

### All Users (Requires Admin)
C:\ProgramData\Autodesk\Revit\Addins\{VERSION}\duHastNet.DocManager.bundle\Contents\

### Current User (No Admin Required)
%APPDATA%\Autodesk\Revit\Addins\{VERSION}\duHastNet.DocManager.bundle\Contents\

Replace {VERSION} with: 2025, 2026 as needed.

## Settings Location

User settings are stored at:
%APPDATA%\DocManager\

Settings files:
- DatabaseConnection.json
- CurrentFolderManager.json
- CloudDocumentManager.json

## Icon Resources

Optional icon for ribbon button:
- Location: Resources\DocManager32.png
- Size: 32x32 pixels

## Version History

v1.0.0 - Initial Release
- Basic launcher functionality
- Singleton window pattern
- Independent WPF window
- No Revit API interaction

## Known Limitations

1. Requires Revit to be running (add-in is a launcher only)
2. Window closes when Revit closes
3. No Revit model interaction
4. Settings are per-user (not per-project)

## Build Notes

### Post-Build Event (Optional)
Copy output to Revit addins directory for testing:

xcopy "$(TargetDir)*.*" "C:\ProgramData\Autodesk\Revit\Addins\2025\duHastNet.DocManager.bundle\Contents\" /Y /I /E

### Files to Exclude from Deployment
- RevitAPI.dll (provided by Revit)
- RevitAPIUI.dll (provided by Revit)
- *.pdb (debug symbols - optional)
- *.xml (documentation - optional)
