duHast.Revit.Annotation.Export.to_data_tag module¶

Reads the tags in a view into DataTag instances.¶

  • one collector per class of tag: independent tags (any category, keynotes included) and the spatial element tags (room, space, area), which are NOT independent tags in Revit

  • reuses independent_tags_tagged_elements and independent_tags_elbow_properties rather than reading those again

  • adds what those leave out: the tag’s type and the tagged element’s category, family name, type name and location (through the link transform for an element in a linked model)

Raw measurements only: millimetres in the model’s own coordinates, as DataItem writes them. Where a tag sits relative to its element is for the user of the data to work out.

A tag that cannot be read is skipped and named in problems (or take_problems), never half written.

duHast.Revit.Annotation.Export.to_data_tag.take_problems()¶

The lines for every tag skipped since the last call, and clears them.

The viewport export reads tags without a list of its own to report into, so the skipped ones collect here and whoever started the export asks for them afterwards.

Returns:

One line per skipped tag.

Return type:

[str]

duHast.Revit.Annotation.Export.to_data_tag.pick_leader_entry(entries, host_id, link_id, index)¶

The leader properties belonging to one tagged element.

Revit 2022 onwards gives one entry per tagged reference, each naming its element (and the linked element when it is in a link). Earlier versions give a single entry without ids. Matched on ids first; only when no entry names any id is the position used.

Parameters:

  • entries ([dict]) – The output of get_elbow_properties.

  • host_id (int) – Element id of the tagged element in this model, -1 when it is in a link.

  • link_id (int) – Element id of the tagged element in the link, -1 when it is in this model.

  • index (int) – Position of the tagged element in the tag’s list.

Returns:

The matching entry, or None.

Return type:

dict or None

duHast.Revit.Annotation.Export.to_data_tag.spatial_tag_to_data(doc, tag, kind)¶

Converts one room, space or area tag.

The Revit API for these differs from independent tags: they refer to one spatial element, have a single leader, and no rotation. Anything not available on a version is left unread.

Parameters:

  • doc (Autodesk.Revit.DB.Document) – Current Revit model document.

  • tag (Autodesk.Revit.DB.SpatialElementTag) – The tag.

  • kind (str) – One of DataTagKindNames.

Returns:

The tag as data.

Return type:

DataTag
