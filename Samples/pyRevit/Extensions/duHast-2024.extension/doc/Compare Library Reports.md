# Compare Library Reports

## Overview
Compares reports from different family libraries to identify differences, duplicates, or missing families across multiple library locations.

## Prerequisites
- CSV reports must first be created using the "Report Families in Library" function
- Multiple library directories with existing CSV reports

## Functionality
This tool allows you to:
- Select multiple library directories containing CSV reports
- Compare family data across different libraries
- Identify discrepancies between library collections
- Generate comparison analysis

## Usage Steps
1. Click the "Compare Library Reports" button
2. Select directories containing library CSV reports
3. Choose specific CSV files to compare from the presented list
4. Review the comparison results in the pyRevit output window

## Input Requirements
- Existing CSV report files generated by the library reporting function
- Read access to library directories
- CSV files must follow the standard library report format

## Output
- Comparative analysis displayed in pyRevit console
- Identification of differences between selected libraries
- Status messages indicating success or failure of the comparison

## Error Handling
- Validates that directories contain valid CSV reports
- Handles cases where no files are selected
- Provides clear error messages for invalid file formats

## Notes
- This function is part of the family library management workflow
- Best used after generating individual library reports
- Helps maintain consistency across multiple family libraries
